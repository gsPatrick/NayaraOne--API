# ADR 0012 — K12 401 x 403

## Contexto
A auditoria cega da parte 3 do bloco de governança apontou a contradição K12 (401 x 403) entre o livro e/ou entre as demandas. Demandas afetadas: D850.

## Decisão
403 = acesso negado; 401 = sessão expirada, vai ao login com `returnTo`, nunca a "sem acesso"

## Alternativas
Tratar 401 como "sem acesso". Rejeitada: sessão expirada leva ao login com `returnTo`; só 403 vira acesso negado.

## Consequências
O Front redireciona 401 ao login e mostra "acesso negado" só no 403 (estados de tela, D850).
