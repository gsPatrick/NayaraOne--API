# ADR 0013 — K13 README

## Contexto
A auditoria cega da parte 3 do bloco de governança apontou a contradição K13 (README) entre o livro e/ou entre as demandas. Demandas afetadas: D800.

## Decisão
D800 cria o esqueleto com os 9 títulos exigidos por D891; cada dona preenche

## Alternativas
Cada dona criar o README do seu jeito. Rejeitada: o esqueleto com os 9 títulos de D891 nasce em D800 e cada dona o preenche.

## Consequências
Os 8 READMEs têm as mesmas 9 seções; D891 as confere por teste.

## Data
2026-10-28

## Responsável
Patrick (dono do projeto), pela regra de que o livro manda e o que o livro não resolve vira decisão registrada.
